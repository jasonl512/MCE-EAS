## Manhattan Green Project Catalog

This catalog summarizes potential green infrastructure and landscape projects that may improve a site’s greenness or green-factor score. For each project, it lists a brief description, an estimated cost range, an estimated construction timeframe, and reference sources.

The scoring pathways use Seattle Green Factor guidance as a comparison framework; they are not an official New York City scoring method. Cost and schedule figures are preliminary planning estimates and will vary with site conditions, project size, design, and permitting. Review the linked sources before using the catalog for budgeting or project decisions.
