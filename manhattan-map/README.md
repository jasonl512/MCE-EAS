# Manhattan Street Network Flow Map Prototype

A Jupyter Notebook prototype that models a maximum-flow problem on a Manhattan street network and displays the street segments on an interactive map. 
The notebook is an early network-analysis prototype; it does not calculate a NYC GreenScore or Seattle Green Factor score.
